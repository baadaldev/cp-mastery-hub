## 📖 About CP Mastery Hub
**CP Mastery Hub** is a comprehensive, production-ready development platform designed to guide computer science students and software engineers through their **entire 3-year university competitive programming journey** from complete beginner (*Bronze Cadet / 0 CF*) to expert problem solver (*Gold Candidate Master / 1900+ CF* and FAANG ready).

---

## ⚡ Core Feature Modules

### 1. 👁️ Interactive Algorithm & Code Visualizer Studio
- Step-by-step visual animation engine for:
  - **Sorting Algorithms:** Bubble Sort, Selection Sort, Insertion Sort with bar height transformations, comparison highlights, and swap counters.
  - **Binary Search:** Interactive window boundary narrowing (`low`, `mid`, `high`) with target matching.
  - **Two Pointers & Sliding Window:** Real-time pointer movement (`left` and `right` arrows) with condition verification.
- **Controls:** Play/Pause, Step Forward, Step Backward, Speed adjustment, and random array generator.
- Real-time step execution inspector logs what each line of algorithm logic is doing.

### 2. 🗺️ 3-Year Structured University Roadmap
- **Year 1 (Foundations & STL Mastery):** C++ STL, Fast I/O, Number Theory, Sieve of Eratosthenes, Two Pointers.
- **Year 2 (Core DSA & Algorithmic Power):** Binary Search on Answer, Graph Traversals (BFS/DFS), Disjoint Set Union (DSU), 1D & 2D Dynamic Programming.
- **Year 3 (Advanced CP & Candidate Master):** Segment Trees, Fenwick Trees (BIT), Binary Lifting (LCA), Bitmask DP, Game Theory & Sprague-Grundy.
- Integrated interactive checklist with **local storage persistence**.

### 3. 💻 Code Studio & 1-Click Direct GitHub Push
- Clean web code editor supporting **C++ (Fast I/O templates)**, **C (Standard C99)**, and **Python 3**.
- **1-Click GitHub Push:** Commits your solutions directly to any repository on your GitHub account (`baadaldev`) using the GitHub REST API!
- Auto-creates the target repository if it does not already exist.

### 4. 🧠 14 Core Algorithmic Patterns Handbook
- Visual guide and ready-to-copy C++ canonical templates for the 14 essential patterns:
  1. Two Pointers
  2. Sliding Window
  3. Fast & Slow Pointers (Floyd's Cycle)
  4. Monotonic Stack
  5. Binary Search on Answer
  6. Breadth-First Search (BFS)
  7. Disjoint Set Union (Union-Find)
  8. Topological Sort (Kahn's)
  9. Dynamic Programming State Compression, and more.

### 5. 🏆 Live Contest Radar
- Live countdown timers and registration links aggregated for:
  - **Codeforces**
  - **LeetCode**
  - **AtCoder**
  - **CodeChef**

### 6. 🤖 Socratic AI Problem Coach
- Progressive 4-level hint system that guides problem solving without spoiling the full solution:
  - Level 1: Core Observation & Intuition
  - Level 2: Recommended Data Structure & Strategy
  - Level 3: Algorithm Invariant / Pseudocode
  - Level 4: Edge Cases & Gotchas

## 🛠️ How to Run Locally

Because CP Mastery Hub is built with modern, zero-dependency client architecture:

1. Clone the repository:
\`\`\`bash
git clone https://github.com/baadaldev/cp-mastery-hub.git
cd cp-mastery-hub
\`\`\`

2. Open \`index.html\` directly in Google Chrome, Edge, or Brave:
\`\`\`bash
# On Windows PowerShell
start index.html
\`\`\`
