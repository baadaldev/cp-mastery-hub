# Sorting and Searching Algorithms Guide

Understanding sorting and searching primitives is crucial for competitive programmers and software engineers.

## Comparison Sorting Algorithms

- **Merge Sort**: Stable sort with guaranteed O(N log N) worst-case time complexity.
- **Quick Sort**: In-place algorithm with average O(N log N) performance; standard in std::sort.
- **Heap Sort**: O(N log N) comparison sort using a binary heap structure.

## Binary Search & Two Pointers

- **Binary Search on Answer**: Monotonic search spaces allowing range reduction in O(log(High - Low)).
- **Two Pointers Technique**: Optimizing pair searches and subarray sliding windows from O(N^2) to O(N).
